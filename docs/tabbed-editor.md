# Tabbed editing and window commands

Each tab owns `Session`: buffer service and undo history, selection/cursor, search service and fields, file/save lifecycle, transfers, viewport and pending caret navigation. The active session is held by the shell; inactive slots own their complete sessions. Switching transfers ownership rather than loading text into another buffer. New/Open preserve dirty existing documents. Paths already open are selected by canonical path; Finder's file array and command-line arguments open every supplied file.

The existing file/clipboard barriers remain authoritative. Switching waits for the current session's accepted commands, transfers and file work to settle. Close applies only to the active tab. Window close and Quit walk the remaining tabs through the same asynchronous save/discard/cancel flow. A cancelled prompt or save stops the quit sequence. Closing the final tab exits. Tabs and unsaved text are not persisted across process restarts.

`chrome.rs` owns tab-strip and F-panel geometry. Document painting and pointer input share a viewport translated below the tab strip; the F-panel occupies space below the document footer. Search, scrollbars, context-menu caret positioning and details cards use that document space. Appearance and software cursors use full-scene coordinates. The entire scene still uses the platform framebuffer's aspect-fit transform.

The F-panel is one optional line and calls the same typed intents as F1–F12. Labels follow the active editor, search or Appearance context. At small resolutions it prioritizes the active task rather than wrapping. Holding Cmd, Option, Control and Shift on the keyboard selects alternate command labels and actions. Modifier controls are not drawn. When all twelve slots fit, F-key positions stay fixed; narrow layouts prioritize the available task commands. Appearance offers Keep, Previous/Next preset, Back and Reset. Search prioritizes Next/Previous match, replacement and Back. Ctrl+Tab/Ctrl+Shift+Tab and Cmd+Shift+]/[ navigate tabs. Shift+F10 retains the context menu. Diagnostics moved to the View menu to free F3 for Find.

Zoom uses a native binary mask plus a fractional presentation scale. The same scaled character and line metrics feed text, selection, caret, wrapping and hit testing. Zoom changes by 10%, with 100% reset; it does not generate antialiased font masks.

Native acceptance on 2026-11-08 covered two command-line files, separate edits and undo, F6 New/F8 Next/F10 Close, cancelling a dirty close, clickable 10% zoom, hover help, actual bitmap specimens, typed font search, immediate keyboard font preview with no disk write, Escape rollback, dragging the panel with its popup, and Pixel cursor selection/context shapes. Metal readback tests validate binary masks and nearest-texel letterboxing. Automated geometry tests cover 256×192 and larger scenes.
